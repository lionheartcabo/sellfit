Stripe prohibited businesses

Stripe’s restricted-businesses page lists categories that cannot use Stripe, plus restricted businesses that need extra due diligence. This page is only the prohibited rows from sellfit’s 2026-08 dataset (15 rules). For restricted_review categories, see stripe-restricted-businesses.html. Polar sits on Stripe, so a Stripe prohibition often blocks Polar too.
