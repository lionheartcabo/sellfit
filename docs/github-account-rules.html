GitHub account rules

GitHub’s Terms of Service say a human must create an Account. Machine accounts are allowed when a human sets them up and accepts the Terms. Accounts registered by bots or other automated methods are not permitted. sellfit encodes these as cited rules — and treats human-creates / machine-account as account setup notes, not product-fit ALLOWED defaults for an arbitrary idea.

Account creation and machine accounts

These two rules are about who may open a GitHub account, not whether a product idea is allowed on GitHub as a host. In the CLI, sellfit marks them n/a for ordinary product-fit checks so they do not fake-ALLOW an idea. Use them when the question is “can a bot self-register?” or “is a machine account OK?”

github-human-creates allowed human-creates-account

A human must create the GitHub account; machine accounts are permitted if a human sets them up.

“You must be a human to create an Account. Accounts registered by "bots" or other automated methods are not permitted.”

https://docs.github.com/en/site-policy/github-terms/github-terms-of-service · effective 2026-04-27 · checked 2026-08-16

github-machine-account allowed machine-account

GitHub permits one free machine account set up by an individual human who accepts the Terms.

“A machine account is an Account set up by an individual human who accepts the Terms on behalf of the Account, provides a valid email address, and is responsible for its actions.”

https://docs.github.com/en/site-policy/github-terms/github-terms-of-service · effective 2026-04-27 · checked 2026-08-16
