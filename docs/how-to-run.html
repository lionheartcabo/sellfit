How to run sellfit

sellfit is an offline MIT CLI plus a cited 2026 merchant-policy dataset. Paste a one-line product idea; get the worst matching verdict per platform (Polar, Lemon Squeezy, Stripe, Chrome Web Store, GitHub) with quote, URL, and last-checked date. No model at runtime. No network in default runs.

Repo: github.com/lionheartcabo/sellfit · release v0.1.0 · agents: AGENTS.md

Guides: sellfit dataset · How to run · Polar acceptable use · Lemon Squeezy prohibited products · Stripe restricted businesses · Chrome Web Store program policies · GitHub account rules

Install (clone only)

No package registry publish in this window. Clone the public repo and run with the system Python 3 interpreter. Tests stay offline.

Clone and verify

git clone https://github.com/lionheartcabo/sellfit.git
cd sellfit
python3 -m unittest discover -s tests -v
python3 -m sellfit platforms

Check a product idea

Human-readable output first. Agents should add --json (one JSON object, no extra prose).

Examples that should pass / fail

python3 -m sellfit check "MIT-licensed CLI that checks Polar AUP"
python3 -m sellfit check "cold email SaaS"
python3 -m sellfit check "MIT-licensed CLI that checks Polar AUP" --json

Exit 0 = at least one product-fit platform is allowed or restricted_review. Exit 2 = every product-fit platform is prohibited (n/a omitted). Exit 1 = usage error.

  • platforms — list covered surfaces and rule counts.
  • cite <rule_id> — print one rule’s quote + source URL (e.g. polar-8).
  • diff old.json new.json — offline list of added/removed/changed rules (Pro watch shape; Pro itself is not for sale yet).

What this is / is not

  • Is: a keyword + category matcher over a dated JSON cut of public policy pages (v0 last_checked 2026-08-16).
  • Is not: legal advice, a Polar/Lemon/Stripe reviewer, a guarantee of approval, a paid directory, or a tip jar.
  • Chrome Web Store rules apply only when the idea is an extension/theme/add-on; otherwise the CLI marks CWS n/a.
  • GitHub account-creation rules are publish-account notes, not product-fit ALLOWED defaults.
  • Polar checkout is not open. Pro (12 USD/mo policy-diff + CI watch) is not for sale. Free Pro waitlist.

Official sources to re-check: Polar AUP, Lemon prohibited products, Stripe restricted businesses, CWS program policies, GitHub Terms of Service.
