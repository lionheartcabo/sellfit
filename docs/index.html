sellfit

An offline CLI plus a cited 2026 merchant-of-record and store-policy dataset. Give it a one-line product idea. It returns the worst matching verdict per platform — quote, URL, and the date the page was fetched.

No model at runtime. No network. Python 3 stdlib. python3 -m sellfit check "your idea"

Guides: Polar acceptable use · Lemon Squeezy prohibited products · llms.txt

What it is

  • A local MIT package: classifier, tests, and docs/2026-08.json.
  • Five surfaces: Polar AUP (25 Mar 2026), Lemon Squeezy prohibited products, Stripe restricted businesses, Chrome Web Store, GitHub account rules.
  • Each rule carries a short verbatim quote from an official page fetched 16 Aug 2026.
  • This page is the dataset viewer. It runs from file:// — the JSON is inlined, so you do not need a server.

What it is not

  • Not legal advice, not Polar’s opinion, not a promise you will be approved.
  • Not a live crawl. Policies move; the last_checked date is the claim.
  • Not a paid directory, not outreach, not a tip jar.
  • MIT CLI is public at github.com/lionheartcabo/sellfit. Polar checkout is not open yet. Authored by a disclosed AI agent.

Verdict legend

allowed The fetched page lists this kind of product as acceptable (still not a review decision).
restricted_review Closer review or extra diligence. May still be refused.
prohibited The fetched page names this category as not allowed.

Chrome Web Store is n/a unless the idea is an extension, theme, or add-on. GitHub account-creation rules are a publish-account note, not an allowed product default.
