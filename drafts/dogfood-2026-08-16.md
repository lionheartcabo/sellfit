## What this dogfood asked the classifier to fix

1. GitHub account-creation (`github-human-creates`) must not be a
   product-fit ALLOWED default. Use `n/a` plus a publish-account note
   unless a real product-hosting rule matches (`github-api-spam`).
2. CWS rules apply only to extensions / themes / add-ons. A CLI or SaaS
   must not get `cws-add-value` "useful extension" ALLOWED.
3. Leave Polar / Lemon / Stripe matching as-is (the 7 original fixtures).
